# ValutaTrade Hub

Консольное приложение-симулятор валютного кошелька на Python. Реализует регистрацию пользователей, мультивалютный портфель, покупку/продажу валюты по курсу и ведение логов операций.

---

## Возможности

Программа поддерживает полный цикл работы с мультивалютным портфелем через CLI-интерфейс:

### Управление пользователями
- **Регистрация** нового пользователя с проверкой уникальности логина. Если пользователь уже существует — система корректно возвращает ошибку вместо перезаписи данных.
- **Авторизация (вход)** по логину и паролю с валидацией учётных данных.

### Операции с портфелем и кошельками
- **Автоматическое создание кошельков**: при регистрации пользователю назначается базовый USD‑кошелёк с начальным балансом.
- **Добавление новых валют** в портфель: динамическое создание кошелька для любой поддерживаемой валюты при первой операции.
- **Просмотр портфеля**: отображение баланса по каждой валюте и общей стоимости портфеля в USD (с учётом текущих курсов).

### Торговля валютой
- **Покупка валюты** по фиксированному курсу (через аргумент `--rate`). Система проверяет достаточность средств в базовой валюте (USD) и обновляет балансы.
- **Продажа валюты** по фиксированному курсу. Система проверяет наличие объёма в кошельке и зачисляет выручку в базовую валюту.
- **Работа с дробными объёмами**: поддержка операций с малыми объёмами криптовалют (например, 0.001 BTC) с корректным расчётом сумм.

### Инфраструктура и контроль
- **Логирование всех действий**: каждая операция (регистрация, вход, покупка, продажа) фиксируется в файле `actions.log` с временной меткой, типом операции, пользователем и деталями транзакции.
- **Обработка ошибок**: валидация входных данных, обработка ситуаций «недостаточно средств», «валюта не найдена», «пользователь не авторизован» через кастомные исключения и понятные сообщения.

## Структура проекта
-valutatrade_hub/: основной код приложения.
-cli/interface.py: точка входа CLI, парсинг аргументов.
-core/models.py: модели User, Wallet, Portfolio.
-core/usecases.py: бизнес-логика операций.
-parser_service/: работа с внешними API (CoinGecko, ExchangeRate-API).
-infra/logging_config.py: конфигурация логирования.
-data/: хранилище данных (JSON-файлы с пользователями, портфелями, курсами).
-demo_output.txt: текстовый лог работы сценария.
-.gitignore: правила исключения временных файлов.

### Зависимости и инструменты
Python 3.14+
uv (управление зависимостями и запуск)
hatchling (упаковка проекта)
ruff (линтер)

### Логирование
Все действия пользователей записываются в файл actions.log в корне проекта. Формат записи включает:

-timestamp;
-тип операции;
-пользователя;
-детали транзакции.
