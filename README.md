## Описание проекта

ValutaTrade Hub — консольное приложение на Python, имитирующее работу валютного кошелька и обменника. Реализованы:

- Регистрация и авторизация пользователей с хешированием паролей.
- Управление портфелем: создание кошельков, покупка/продажа валюты.
- Хранение данных в JSON-файлах.
- Сессионный вход (сохранение текущего пользователя между запусками CLI).
- Получение курсов валют (на текущем этапе — из локального файла `data/rates.json`; в следующих спринтах планируется подключение внешнего API).

## Стек технологий

- Python 3.11+
- Стандартная библиотека (`argparse`, `json`, `pathlib`, `hashlib`)
- Система управления зависимостями: `uv`
- Линтер и форматтер: `ruff`
- ОС: Windows 64-бит (MINGW64)
